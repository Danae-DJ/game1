# game1
This is my first game; working with JavaScrit
The game is a simplified version of Asteroids in which our ship must avoid colliding with enemy projectiles; each round ends when our ship is hit.


You Need to have:
install NODE.js
Install GIT
install Live Server

How to create this game:
1. create the base of the game, the space where the player'll play the space ship
2. create the space ship, this object working with `cavas`; where we need create the mothod and bucle to move the space ship only in the base of game.
3. create the projectiles of our space ship.
